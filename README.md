# JavaScript-project-1 - FridgeKeeperr

Небольшой портфолио-проект на **HTML, CSS и JavaScript** для учёта продуктов и контроля сроков годности.

## Возможности

- добавление, редактирование и удаление продуктов;
- категория, количество и срок годности;
- автоматические статусы: свежий продукт, скоро истекает, годен до сегодня, срок истёк;
- поиск по названию и категории;
- фильтры по сроку годности и сортировка;
- сводные счётчики;
- сохранение в `localStorage` без регистрации и backend;
- адаптивный интерфейс и базовая поддержка клавиатуры.

## Запуск

1. Скачайте папку проекта.
2. Откройте `index.html` в браузере. Для обычного использования сборщик и npm не нужны.

При первом запуске появятся несколько демонстрационных продуктов. Все изменения сохраняются в локальном хранилище текущего браузера.

## Структура

- `index.html` - разметка и доступные элементы интерфейса.
- `styles.css` - адаптивная стилизация.
- `app.js` - CRUD, фильтрация, сортировка, проверка формы, расчёт сроков и хранение данных.

## Дизайн

Интерфейс использует системные шрифты и холодную палитру: индиго для основных действий, бирюзу для свежих продуктов, янтарный для предупреждений и коралловый для просроченных продуктов.

> Демо-проект. Счётчики сроков годности рассчитываются в браузере по локальной дате пользователя; сетевое хранилище не подключено.
